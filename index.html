01

GD Data Platform: AI Training Data Library & Video Hosting

Python · FastAPI · SQLAlchemy · MySQL · FAISS · OpenAI · HLS · Nginx

  • Built and managed the backend for an AI training data platform that hosts, searches and streams human trajectory datasets for Computer Use Agents.
  • Designed database-level multi-filter search (tool, category, OS, duration, action count, price, trajectory quality) with pagination, indexes and selected-column queries.
  • Implemented RAG-style semantic search with FAISS and OpenAI embeddings across tasks, videos, prompts and trajectories.
  • Added HLS/m3u8 conversion and metadata APIs; cut response times with query tuning, cache tables and optimized joins.
02

SROT: Intelligent Data Recording Agent

Python · PyQt6 · OpenCV · FFmpeg · Playwright · Pynput

  • Desktop agent that records screen activity, keystrokes, mouse movement and scrolling as structured logs for Computer Use Agent training data.
  • Real-time event logging, activity grouping and browser interaction capture with Playwright-based link extraction.
  • Shipped several production iterations used internally for dataset preparation and quality improvement.
03

OSRM Routing & Rider Tracking System

Python · Django · OSRM · MySQL · Linux · Nginx · ETL

  • Wrote ETL pipelines to clean, validate and transform large Excel, CSV, API and database datasets.
