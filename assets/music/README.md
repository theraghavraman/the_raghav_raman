# Portfolio soundtrack

The portfolio music player is opt-in and self-hosted. It expects this file:

`assets/music/observatory-ambient.mp3`

## Free-music sources worth checking

These are discovery sources, not blanket permissions: confirm the licence on the individual track page before downloading or redistributing the audio.

1. **[Pixabay — CC0 music search](https://pixabay.com/music/search/cc0-license/)** — start here for tracks marked CC0. Look for ambient, cinematic, electronic, or instrumental music. Confirm the track's displayed licence and any platform-specific restrictions before adding it to the repository.
2. **[FreePD archive on GitHub](https://github.com/0lhi/FreePD)** — an archived collection whose repository declares **CC0-1.0**. Browse the *Zoned*, *Electronic*, and *Scoring* folders for atmospheric options. Verify the track file and repository licence before reuse.
3. **[Free Music Archive — licence guide](https://freemusicarchive.org/License_Guide)** — useful for understanding track-specific Creative Commons terms and attribution requirements. Prefer CC0 or CC BY for a portfolio that may be used professionally; avoid **NC** licences if commercial use is possible.
4. **[Creative Commons CC0](https://creativecommons.org/public-domain/cc0/)** and **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)** — read the actual terms. CC BY permits commercial reuse and redistribution with appropriate credit; CC0 is intended to waive copyright to the extent possible.

### Recommended sound for this portfolio

Look for a gentle ambient / cinematic instrumental that complements the ivory, sage, and copper visual palette. Avoid vocals, abrupt transitions, loud intros, and tracks that distract from reading. Preview the complete track before choosing it.

## Add a track

1. Open the individual track's source page and confirm the licence explicitly permits your intended use, including redistribution of the audio file from a public GitHub repository and playback on a public website.
2. Save the downloaded audio here as `observatory-ambient.mp3`. If the source file is already MP3, do not re-encode it unnecessarily.
3. Add a `CREDITS.md` file in this folder recording the track title, creator, original track URL, exact licence and licence URL, download date, and any changes made. For CC BY, provide the attribution required by the licence.
4. Keep the file reasonably small (ideally a few MB) so the portfolio remains fast on mobile. Check playback on desktop and mobile.

**Important:** a site describing music as “free” or “royalty-free” does not automatically mean the standalone audio may be redistributed in a public source repository. Keep a copy or screenshot of the licence/permission details with your project records. Avoid tracks with unclear rights, download-only licences, or Content ID / platform restrictions you cannot satisfy.

No audio track is currently bundled. The player displays a helpful status until a licensed file is added. Audio is never automatically played; the player pauses when the page is hidden.
