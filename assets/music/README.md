# Portfolio soundtrack

The portfolio music player is opt-in and self-hosted. It expects this file:

`assets/music/observatory-ambient.mp3`

## Add a track

1. Choose an instrumental/ambient track whose licence explicitly permits redistribution from a public website. A Creative Commons **CC0** or **CC BY** track is a useful starting point; avoid NC licences if you may use the portfolio commercially.
2. Verify the individual track's licence and download/redistribution terms on the creator's own page. Search directories such as [Free Music Archive's filtered instrumental search](https://freemusicarchive.org/search/?adv=1&d=0&music-filter-CC-attribution-only=1&music-filter-commercial-allowed=1&music-filter-public-domain=1&music-filter-remix-allowed=1&only-instrumental=1&sort=_score).
3. Save the audio as `observatory-ambient.mp3` in this folder. Keep the original licence/credit information in `CREDITS.md` and display required attribution on the site.
4. Keep the file reasonably small (ideally a few MB) so the portfolio remains fast on mobile.

No track is bundled yet, so the player displays a helpful status until the licensed audio file is added. Audio is never automatically played; the player pauses when the page is hidden.
